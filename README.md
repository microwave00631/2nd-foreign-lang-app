# 語彙トレ — 第二外国語 語彙強化PWA

日本語話者向けの、第二外国語(中国語・タイ語)の語彙を間隔反復(SRS)で強化するインストール可能なWebアプリ(PWA)です。バックエンド不要・静的ホスティングのみで動作します。

## 主な機能

- **単語の翻訳・検索** — 内蔵辞書(中国語 HSK1〜2 約300語 / タイ語基礎 約220語)を優先検索し、見つからない単語は翻訳API(MyMemory・キー不要)へフォールバック。中国語のAPI結果にはピンインを自動付与
- **学習DB** — 翻訳した単語・学習中の単語・出題履歴をすべて端末内の IndexedDB に保存(オフラインで動作)
- **SRS(SM-2)による差分学習** — 学習者の習熟状況とアプリ辞書の「差分」を、毎日のクイズで自動的に埋めていきます。新規語は辞書からレベル順(HSK1→HSK2→…)に1日10語(設定可)ずつ自動投入
- **学習段階に応じた出題形式** — 未学習: 提示カード+選択式(認識)→ 学習中: 選択式(認識/想起)→ 復習中: 選択式/タイピング → 習得済み: タイピング(産出)
- **タイピングの柔軟な判定** — ピンインは声調記号・数字・無声調いずれも受理(設定で厳格化可)。タイ語はローマ字またはタイ文字
- **夜のリマインダー通知** — 設定した時刻(既定21:00)に未消化の復習があれば通知
- **統計** — 連続学習日数(ストリーク)、学習段階の内訳、直近30日のレビュー数
- **発音再生(TTS)** — ブラウザの SpeechSynthesis を使用(対応音声がない端末ではボタンが無効化)

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト(SRSエンジン・回答判定)
npm run build    # 型チェック + 本番ビルド
npm run preview  # 本番ビルドの確認(SW・通知のテストはこちらで)
```

> Service Worker と通知は本番ビルド(`npm run preview`)でのみ動作します。

## 通知の仕組みと制約

PWA単体では「アプリを完全に閉じた状態への定時プッシュ」はできないため、3層構成にしています:

1. **アプリ内バナー** — 起動時に通知時刻を過ぎていて復習が残っていれば表示(常に動作)
2. **フォアグラウンド通知** — タブ/アプリが開いている間、通知時刻から1時間以内に1日1回 OS 通知
3. **Periodic Background Sync** — Chrome でインストール済みの場合のみ、アプリを閉じていても OS のタイミングで通知(ベストエフォート)

確実なクローズ状態への配信が必要になったら、Web Push サーバー(例: Cloudflare Worker + `web-push`、50行程度)を追加するのが次のステップです。

## 翻訳API

- **MyMemory**(既定): 無料・キー不要。設定でメールアドレスを登録すると1日あたりの利用枠が増えます
- **DeepL API Free**(任意): 設定画面でAPIキーを入力。中国語のみ対応(DeepLはタイ語非対応のため、タイ語は常にMyMemory)
- タイ語のAPI翻訳結果には自動でローマ字読みが付かないため、保存前に読みを手入力します

## 技術スタック

React 18 + TypeScript + Vite / Dexie(IndexedDB)/ vite-plugin-pwa(injectManifest + カスタムSW)/ pinyin-pro(遅延ロード)/ Vitest

## データについて

辞書データ(`public/dict/*.json`)は初回起動時に IndexedDB へ取り込まれ、`version` フィールドの更新時のみ再インポートされます。学習データはすべて端末内に保存され、外部に送信されません(翻訳API利用時の検索語を除く)。
